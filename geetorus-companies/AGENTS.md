# AGENTS.md — geetorus-companies

## Purpose
Example and reference company configurations for Geetorus.
Each top-level folder is a separate company config.

## Structure
  default/                    → Default company template
  clawteam-capital/           → Example: capital company
  clawteam-engineering/       → Example: engineering company
  agency-agents/              → Example: agency config
  (other dirs)                → Additional company examples

## Rules
- Each company dir has its own config files
- Do not cross-contaminate company configs
- README.md in each company dir describes its purpose
- skills/ dir contains shared skill definitions

## Fast Fix Guide
- Wrong company context → check you are in the right subdirectory
- Missing skill → check skills/ at root
