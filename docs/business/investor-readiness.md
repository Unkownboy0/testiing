## 3. Risk Matrix & Mitigations

- **Risk**: Upstream foundation model pricing/API changes.
  - *Mitigation*: Adapter architecture decouples core logic; instant model switching via OpenRouter or Ollama.
- **Risk**: Sandboxed code execution security breaches.
  - *Mitigation*: Multi-layer isolation (Docker / e2b microVMs), mandatory company-scope filtering, and human approval gates.
