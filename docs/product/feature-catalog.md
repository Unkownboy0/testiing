# Geetorus — Feature Catalog & Capability Matrix

This matrix provides an evidence-based audit of all platform features in Geetorus across the core repositories (`geetorusai`, `companies-tool`, `geetorus-companies`, `geetorus-market`, `geetorus-docs`).

Statuses:
- **Verified working**: Code, schemas, routes, and UI components exist and are operational.
- **Implemented, not fully verified**: Implemented in code/schema; requires end-to-end multi-cloud/external provider verification.
- **Partially implemented**: Core backend or UI exists, with documented gaps.
- **Mock/demo only**: Present in UI prototypes/fixtures but lacks dynamic backend hooks.
- **Planned but not implemented**: Outlined in ROADMAP.md or specifications.
- **Missing / Deprecated**: Abandoned or superseded legacy components.
